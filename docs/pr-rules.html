Integration standards

Pull Request Rules

Every experiment reaches main through a reviewed pull request from its matching group branch.

Target and title

Target branch: main

Source branch: matching group-<experiment> branch

Title: [Group-<ExperimentName>] Implementation complete

Required checklist

  • Works in Chrome, Firefox, or Safari.
  • No browser console errors.
  • Documented test cases pass.
  • Theory contains at least 300 words.
  • Procedure contains at least 4 steps.
  • Simulation is interactive and produces visible output.
  • Quiz contains at least 3 questions with answer handling.
  • README contains input/output specifications and test cases.
  • Only the assigned experiment folder was modified.
  • A screenshot or demo video is attached.

Review rules

The integration team reviews every pull request. The validate-pr status check must pass before merging. Do not merge directly into main.

Changes to shared CSS, shared JavaScript, the root page, documentation, or another experiment require separate integration-team work.
