Course portal overview

Virtual Cryptography Laboratory

A static, browser-based practical portal for the CSS TH ISE Cryptographic Security Systems course, with one shared interface for 16 independent student experiments.

Technology

  • HTML5 and CSS3
  • Vanilla JavaScript (ES6+)
  • Client-side cryptography libraries where required
  • GitHub Pages for static deployment

Experiments

MD5, SHA-1, RSA, MAC, HMAC, Kerberos, Needham-Schroeder, bcrypt, Argon2, Argon2id, Classical Encryption, Extended Euclidean Algorithm, Brute Force, Dictionary Attack, Frequency Analysis, and SSL/TLS.

Run locally

python3 -m http.server 8000

Open http://localhost:8000. A local HTTP server keeps shared assets and experiment pages loading correctly.

Branch model

main is maintained by the integration team. Each experiment has a matching branch such as group-md5 or group-rsa. Groups submit pull requests from their branch to main and work only inside their assigned experiment directory.

Contribution and deployment

Read the Group Instructions, API Specifications, and PR Rules before starting. The portal is designed for GitHub Pages and the full setup process is covered in the Setup Guide.
