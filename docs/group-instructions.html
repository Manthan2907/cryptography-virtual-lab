Student team handbook

Group Instructions

Each group implements one experiment inside its assigned folder. The integration team owns the portal shell and shared behavior.

Your allowed folder

For example, the MD5 group works on branch group-md5 and folder experiments/md5/.

experiments/md5/ ├── index.html ├── script.js └── README.md

What you may edit

  • Content inside the theory section.
  • Content inside the procedure section.
  • Experiment controls and output markup inside simulation.
  • Quiz questions inside quiz.
  • Your folder's script.js and README.md.

What you must not edit

  • Root index.html, css/, or shared JavaScript.
  • .github/, docs/, or another group's folder.
  • The outer structure, tab buttons, IDs, or shared asset paths of your experiment page.

Content requirements

  • Theory: at least 300 accurate words.
  • Procedure: at least 4 clear numbered steps.
  • Simulation: interactive controls with visible output.
  • Quiz: at least 3 questions with answer handling.
  • README: inputs, outputs, dependencies, test cases, and known limitations.

Example workflow

  1. Checkout your assigned group branch.
  2. Work only in your experiment folder.
  3. Run python3 -m http.server 8000.
  4. Test in a current browser and check the console.
  5. Commit, push, and open a pull request to main.

Pull request

Complete the repository pull request template and include screenshots or a short demo, test cases, and known issues. The validation workflow rejects changes outside the assigned experiment folder.
