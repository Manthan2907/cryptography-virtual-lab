1

Prerequisites

Install or confirm these tools before cloning the project:

  • Git for cloning, branching, committing, and submitting work.
  • Python 3 for the lightweight local HTTP server.
  • Modern browser such as Chrome, Firefox, or Safari.
  • GitHub account with access to the course repository.
  • Code editor such as VS Code for editing your assigned folder.
2

Clone the repository

Open a terminal, move to the folder where you keep course projects, and clone the public repository.

Terminal · all platforms
git clone https://github.com/Manthan2907/cryptography-virtual-lab.git
cd cryptography-virtual-lab

After cloning, open the folder in your editor. The repository is static: there is no package installation step and no backend service.

3

Run locally

Use an HTTP server from the repository root. This keeps shared CSS, JavaScript, and experiment pages loading consistently.

macOS / Linux

Bash
cd cryptography-virtual-lab
python3 -m http.server 8000

Open http://localhost:8000.

Windows PowerShell

PowerShell
cd cryptography-virtual-lab
py -m http.server 8000

Open http://localhost:8000.

Stop the server

Terminal
Ctrl+C

Keep the terminal open while testing, then press Ctrl+C when finished.

Branch structure

The integration team maintains main. Each student group works on its own branch and matching experiment folder.

cryptography-virtual-lab/
├── main                         ← integration team
└── group-md5                    ← MD5 group
    group-sha1                   ← SHA-1 group
    group-rsa                    ← RSA group
    group-mac                    ← MAC group
    group-hmac                   ← HMAC group
    group-kerberos               ← Kerberos group
    group-needham-schroeder      ← Needham-Schroeder group
    group-bcrypt                 ← bcrypt group
    group-argon2                 ← Argon2 group
    group-argon2id               ← Argon2id group
    group-classical-encryption   ← Classical Encryption group
    group-extended-euclidean     ← Extended Euclidean group
    group-brute-force            ← Brute Force group
    group-dictionary-attack      ← Dictionary Attack group
    group-frequency-analysis     ← Frequency Analysis group
    group-ssl-tls                ← SSL/TLS group
Example · select your group branch
git checkout group-md5

Replace group-md5 with your assigned branch. Do not develop directly on main.

5

Verify your setup

  1. Open http://localhost:8000 and confirm the brown portal header and experiment cards appear.
  2. Open one card, such as MD5, and click Theory, Procedure, Simulation, and Quiz.
  3. Confirm the experiment page loads shared styling and the active tab changes.
  4. Check the browser developer console. It should contain no red errors.
  5. Confirm your branch with git branch --show-current.
Git verification
git status
git branch --show-current
git log --oneline -1
6

Troubleshooting

“python3” is not recognized

On Windows, use py -m http.server 8000. If neither command works, install Python 3 and enable it in your PATH.

Page looks unstyled

Confirm the server started in the repository root, not inside docs or an experiment folder. Refresh with Ctrl+R.

Port 8000 is busy

Use another port, for example python3 -m http.server 8080, then open http://localhost:8080.

GitHub access fails

Check the repository URL, your internet connection, and whether your GitHub account has been invited to the repository.

Wrong branch

Run git branch --show-current, then switch to the branch assigned to your group.

Experiment script fails

Open the browser console, reproduce the action, and include the exact error and test input in your pull request.

7

GitHub Pages deployment

The integration team publishes the static portal from the main branch.

  1. Open the repository on GitHub and choose Settings.
  2. In the left menu, choose Pages.
  3. Under Build and deployment, select Deploy from a branch.
  4. Choose branch main and folder /(root), then select Save.
  5. Wait for the deployment status to become active and open the published URL.
