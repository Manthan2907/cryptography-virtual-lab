Virtual Cryptography Laboratory

Printable setup guide for students and instructors

Purpose: Set up the static portal locally, select your group branch, verify the shared experiment interface, and understand how the integration team publishes the site.

1. Prerequisites

  • Git for cloning, branching, committing, and pull requests.
  • Python 3 or another static HTTP server.
  • Modern browser such as Chrome, Firefox, or Safari.
  • GitHub account with access to the course repository.
  • Code editor such as VS Code.

2. Clone the Repository

Open a terminal and run these commands:

git clone https://github.com/Manthan2907/cryptography-virtual-lab.git cd cryptography-virtual-lab

The portal is static. No package installation or backend service is required.

3. Run Locally

macOS / Linux

cd cryptography-virtual-lab python3 -m http.server 8000

Open http://localhost:8000.

Windows PowerShell

cd cryptography-virtual-lab py -m http.server 8000

Open http://localhost:8000.

Stop the server

Ctrl+C

Use this in the terminal when finished testing.

4. Branch Structure

main belongs to the integration team. Each group uses its matching branch and experiment folder.

cryptography-virtual-lab/ ├── main ← integration team └── group-md5 ← MD5 group group-sha1 ← SHA-1 group group-rsa ← RSA group group-mac ← MAC group group-hmac ← HMAC group group-kerberos ← Kerberos group group-needham-schroeder ← Needham-Schroeder group group-bcrypt ← bcrypt group group-argon2 ← Argon2 group group-argon2id ← Argon2id group group-classical-encryption ← Classical Encryption group group-extended-euclidean ← Extended Euclidean group group-brute-force ← Brute Force group group-dictionary-attack ← Dictionary Attack group group-frequency-analysis ← Frequency Analysis group group-ssl-tls ← SSL/TLS group
git checkout group-md5

Replace group-md5 with your assigned branch. Never develop directly on main.

5. Verify Setup

  1. Open http://localhost:8000 and confirm the brown header and experiment cards appear.
  2. Open an experiment and click Theory, Procedure, Simulation, and Quiz.
  3. Confirm the shared styling and active tab behavior work.
  4. Check the browser console for red errors.
  5. Confirm your current branch.
git status git branch --show-current git log --oneline -1

6. Troubleshooting

Python command not found

On Windows use py -m http.server 8000. Otherwise install Python 3 and enable PATH integration.

Unstyled page

Start the server from the repository root, not from docs or an experiment folder. Refresh the browser.

Port is busy

Use another port, such as python3 -m http.server 8080.

GitHub access fails

Check the URL, network connection, and repository invitation.

Wrong branch

Run git branch --show-current and switch to the assigned group branch.

Script error

Open the browser console and include the exact error and test input when requesting help.

7. GitHub Pages Deployment

  1. Open the repository on GitHub and choose Settings.
  2. Choose Pages in the left menu.
  3. Select Deploy from a branch.
  4. Choose branch main and folder /(root).
  5. Choose Save, wait for deployment, and open the published URL.
Screenshot description: The Pages settings should show “Deploy from a branch”, branch “main”, folder “/(root)”, and a published status.

Published portal: https://manthan2907.github.io/cryptography-virtual-lab/

8. Getting Help

Before asking for help, record your branch, operating system, browser, command, and exact error message.
