API Specifications

Each browser-side experiment must expose a clear user action and render readable output in its simulation section. These specifications are educational contracts, not production security APIs.

Hash functions

Experiments: MD5, SHA-1

Input: UTF-8 text. Output: lowercase hexadecimal digest. Library: crypto-js or Web Crypto API.

Example: abc → MD5 900150983cd24fb0d6963f7d28e17f72; SHA-1 a9993e364706816aba3e25717850c26c9cd0d89d.
