Cryptography

Welcome to the Cryptography lab. In this lab, we will do virtual experiments to understand the basic mathematical foundations of cryptography, to gain insightful experience by working with fundamental cryptographic applications and to train in the art of design and analysis of information security protocols.

Academic Context: Developed for TE Computer Engineering (CCSS TH ISE · Virtual Lab Development) at Fr. Conceicao Rodrigues College of Engineering (Fr. CRCE), Bandra, Mumbai.

About the Virtual Laboratory

This virtual laboratory provides a standardized, interactive platform where engineering students can explore cryptographic ciphers, hash mechanisms, authentication handshakes, and cryptanalytic attacks through browser-based execution. All modules are designed to run client-side without external dependencies.

To explore the assigned experiments, navigate to the tab. For group branching and contribution instructions, refer to the .

Objective

The primary objectives of the Cryptography Virtual Laboratory are to provide students with rigorous conceptual and practical knowledge in information security:

1. Theoretical Foundations

Understand mathematical concepts underlying classical and modern cryptography including modular arithmetic, prime factorization, and discrete logarithms.

2. Practical Implementation

Simulate symmetric ciphers, asymmetric key generation (RSA), cryptographic hashes (MD5, SHA-1), and authentication codes (MAC, HMAC).

3. Security Protocol Analysis

Trace message sequences, nonce challenges, and session key exchanges in Kerberos, Needham-Schroeder, and SSL/TLS handshakes.

4. Vulnerability & Cryptanalysis

Conduct safe simulations of brute force, dictionary cracking, and frequency analysis to understand cipher weaknesses and defense strategies.

Student Setup & Branching Guide

Each student group is assigned a dedicated branch on GitHub. Do not develop directly on main.

1. Clone Repository & Start Local Server

git clone https://github.com/Manthan2907/cryptography-virtual-lab.git
cd cryptography-virtual-lab
python -m http.server 8000

Open http://localhost:8000 in your browser.

2. Check Out Your Assigned Group Branch

git checkout group-<experiment-name>
# Example for MD5 group:
git checkout group-md5
