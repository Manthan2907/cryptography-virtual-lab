RSA Digital Signature

Generate an RSA digital signature for a given message and verify the signature using the corresponding public key.

Aim & Objectives

Aim: Generate an RSA digital signature for a given message and verify the signature using the corresponding public key.

Objectives:

  • Understand asymmetric authentication and non-repudiation.
  • Understand how RSA uses public and private keys.
  • Generate a digital signature using the private key.
  • Verify the signature using the public key.
  • Detect whether a signed message has been modified.

Theory

A digital signature is a cryptographic technique used to provide authentication, integrity, and non-repudiation. It allows a receiver to verify that a message was created by the claimed sender and was not modified during transmission.

RSA is an asymmetric cryptographic algorithm that uses two related keys: a public key and a private key. The public key can be shared with anyone, while the private key must be kept secret by the owner.

In an RSA digital signature system, the message is first processed using a cryptographic hash function. The resulting hash value is digitally signed using the sender's private key. The receiver uses the sender's public key to verify the signature.

If the message is changed after signing, its hash value also changes. Therefore, the signature verification fails. This property allows digital signatures to detect unauthorized modifications.

The basic RSA relationship is represented as:

Signature = Hash(Message)d mod n

During verification, the receiver uses the public key (e, n) to verify the signature.

In this simulation, RSA signing and verification are demonstrated interactively. The user enters a message, generates its signature, and verifies the signature. A tamper test is also provided to demonstrate that changing the message causes verification to fail.

Procedure

  1. Open the RSA Digital Signature experiment.
  2. Enter a message in the Message Text field.
  3. Click the Sign and Verify button.
  4. The RSA private key is used to create the digital signature.
  5. The RSA public key is used to verify the generated signature.
  6. Observe the signature and verification result.
  7. Click Run Tamper Test to modify the message.
  8. Observe that verification fails for the modified message.
