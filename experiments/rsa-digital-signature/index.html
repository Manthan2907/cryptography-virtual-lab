RSA Digital Signature

Generate an RSA digital signature for a given message and verify the signature using the corresponding public key.

Aim & Objectives

Aim: Generate an RSA digital signature for a given message and verify the signature using the corresponding public key.

Objectives:

  • Understand asymmetric authentication and non-repudiation.
  • Examine the mathematical inverse relationship between encryption with public key and signing with private key.
  • Verify signature integrity and detect altered messages.

Theory

A digital signature is a cryptographic value that guarantees authenticity, non-repudiation, and integrity. In an RSA signature scheme, the signer computes S = Md mod n using their private key d. Any verifier who possesses the signer's public key (e, n) can verify the message by evaluating whether Se mod n == M.

Procedure

  1. Generate prime numbers p and q to compute modulus n = p × q.
  2. Calculate Euler's totient φ(n) and choose public exponent e.
  3. Compute private key d = e-1 mod φ(n).
  4. Sign message text with private key d.
  5. Verify signature with public key e.
