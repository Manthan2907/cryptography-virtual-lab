Access Control List (ACL)

Implement an Access Control List and demonstrate authorization based on assigned permissions.

Aim & Objectives

Aim: Implement an Access Control List and demonstrate authorization based on assigned permissions.

Objectives:

  • Understand object-centric security structures (Access Control Lists) versus capability lists.
  • Add and modify Access Control Entries (ACEs) with fine-grained permissions (r, w, x).
  • Demonstrate real-time authorization checks and permission inheritance.

Theory

An Access Control List (ACL) is a list of permissions associated with a system resource (object). The list specifies who or what is allowed to access the object and what operations are allowed to be performed. Each entry in a typical ACL specifies a subject and an operation (e.g. Alice: Read, Write; Bob: Read; All: None).

Procedure

  1. View the active Access Control Entries (ACE) for the target file.
  2. Optionally add a new user or modify permissions (Read, Write, Execute).
  3. Simulate an access request from a chosen user.
  4. Verify the authorization engine's Allow or Deny decision.
