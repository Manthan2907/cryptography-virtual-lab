# Access Control List (ACL)

Implement an Access Control List and demonstrate authorization based on assigned permissions.

## Input
- Subject identity, file resource identifier, requested access right (Read, Write, Execute)

## Output
- Active ACL table display and authorization decision (Allow / Deny)

## Test
- Add custom ACE (Access Control Entry) to ACL. Verify authorized user access succeeds and non-authorized user access is rejected.
