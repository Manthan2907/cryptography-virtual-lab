Cryptographic Hash Functions

Study and implement a cryptographic hash function to generate a fixed-length hash value for a given input message.

Aim & Objectives

Aim: Study and implement a cryptographic hash function to generate a fixed-length hash value for a given input message.

Objectives:

  • Understand the concept of one-way compression and fixed-length digest generation.
  • Observe deterministic mapping from variable-length inputs to constant-size digests.
  • Analyze digest representations across binary, decimal, and hexadecimal formats.

Theory

A cryptographic hash function H is a mathematical algorithm that maps data of arbitrary size to a bit array of a fixed size (the "hash value", "hash", or "message digest"). It is a one-way function, that is, a function which is practically infeasible to invert.

Procedure

  1. Enter arbitrary text in the input message box.
  2. Select the target hash function (e.g., MD5, SHA-1, SHA-256).
  3. Click "Generate Hash" to execute the algorithm.
  4. Inspect the resulting hexadecimal digest and bit length.
