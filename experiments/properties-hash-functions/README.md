# Properties of Secure Hash Function

Analyze the properties of a secure cryptographic hash function, including preimage resistance, second-preimage resistance, collision resistance, and avalanche effect.

## Input
- Primary message and perturbed message (1-bit variation)

## Output
- Hash digests, Hamming distance between digests, and bit flip percentage (Avalanche effect metrics)

## Test
- Test with two input messages differing by a single bit to verify ~50% bit flip rate demonstrating the avalanche effect.
