RSA Digital Signature with Hash

Generate the hash of a message, create an RSA digital signature using the hash, and verify the signature using the corresponding public key.

Aim & Objectives

Aim: Generate the hash of a message, create an RSA digital signature using the hash, and verify the signature using the corresponding public key.

Objectives:

  • Understand the "hash-then-sign" paradigm in digital signature algorithms.
  • Observe why hashing is necessary to prevent existential forgery and manage arbitrarily large messages.
  • Perform RSA signature generation using private key d and signature verification using public key e.

Theory

In RSA Digital Signatures, signing a message directly with modular exponentiation S = Md mod n is vulnerable to mathematical attacks and is computationally slow for large documents. In standard practice (PKCS#1 v1.5 / PSS), a secure hash h = H(M) is computed first, and the signature is generated by computing S = (h)d mod n. Verification checks if Se mod n == H(M).

Procedure

  1. Generate an RSA key pair (or use demo parameters).
  2. Compute the cryptographic hash (SHA-256) of the input message.
  3. Sign the hash digest using the private key.
  4. Verify the signature using the public key against original and modified messages.
