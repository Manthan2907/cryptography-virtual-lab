EXPERIMENT OVERVIEW

Aim & Objectives

Study the fundamental mechanics of cryptographic hashing through the Secure Hash Algorithm 1 (SHA-1).

Experiment Title

SHA-1: Generate the SHA-1 hash value for a given input message and study its output characteristics and sensitivity to input changes.

Primary Aim

To implement, analyze, and simulate the 160-bit SHA-1 cryptographic hash algorithm, validating its deterministic properties, fixed output length, message compression pipeline, and the avalanche effect when input data undergoes slight mutations.

Educational Objectives

1. Mathematical Foundations

Understand the pre-processing padding (512-bit blocks), 80-step expansion array, and modular 32-bit addition arithmetic.

2. Iterative Compression

Trace the 80 rounds of logical non-linear functions (f0-f79) using round constants (K0-K3) and state registers (A, B, C, D, E).

3. Output Determinism

Generate exact 160-bit (40 hexadecimal characters) message digest and demonstrate avalanche sensitivity to single-bit changes.

THEORETICAL FOUNDATION

Theory • SHA-1 Architecture

The Secure Hash Algorithm 1 (SHA-1) is a cryptographic hash function specified by NIST in FIPS PUB 180-4. It transforms an arbitrary-length message (< 264 bits) into a fixed 160-bit (20-byte) message digest.

1. Merkle-Damgård Iterative Construction

SHA-1 follows the Merkle-Damgård paradigm. The message is padded into an exact multiple of 512-bit blocks ($M_1, M_2, \dots, M_n$). Each 512-bit block sequentially updates five 32-bit internal working state registers ($A, B, C, D, E$) across 80 transformation rounds.

Initial State Registers (Big-Endian Hex):
H0 = 0x67452301  |  H1 = 0xEFCDAB89  |  H2 = 0x98BADCFE  |  H3 = 0x10325476  |  H4 = 0xC3D2E1F0

2. Four Execution Stages of 80 Rounds

The 80 rounds are divided into 4 stages of 20 rounds each. Each stage applies a specific bitwise non-linear function $f_t(B, C, D)$ and a designated round constant $K_t$:

Stage Rounds ($t$) Nonlinear Function $f_t(B, C, D)$ Round Constant $K_t$
Stage 1 (Ch) 0 to 19 (B ∧ C) ∨ (¬B ∧ D) 0x5A827999
Stage 2 (Parity) 20 to 39 B ⊕ C ⊕ D 0x6ED9EBA1
Stage 3 (Maj) 40 to 59 (B ∧ C) ∨ (B ∧ D) ∨ (C ∧ D) 0x8F1BBCDC
Stage 4 (Parity) 60 to 79 B ⊕ C ⊕ D 0xCA62C1D6

3. Per-Round Transformation Equation

In each round $t$ ($0 \le t \le 79$), the temporary register $T$ is computed and state is shifted:

T = S5(A) + ft(B, C, D) + E + Wt + Kt  (mod 232)
E = D  |  D = C  |  C = S30(B)  |  B = A  |  A = T
LABORATORY PROTOCOL

Procedure • Step by Step

Follow this standardized laboratory workflow to simulate SHA-1 message padding, 80-round iterative compression, and avalanche effect evaluation.

Step 1: Input Preparation & Message Padding

Enter an arbitrary ASCII text message. The system appends a single 1 bit (hex 0x80), followed by 0 bits until the message length is congruent to 448 (mod 512). The original 64-bit big-endian message length is appended to form an exact 512-bit block.

Step 2: 80-Word Expansion Array (W0 to W79)

The first 16 words ($W_0 \dots W_{15}$) are extracted directly from the 512-bit block. For $t = 16 \dots 79$, words are generated via: Wt = S1(Wt-3 ⊕ Wt-8 ⊕ Wt-14 ⊕ Wt-16).

Step 3: Execute 80 Round State Transformation

Iterate through rounds 0 to 79. Observe registers A, B, C, D, and E as they undergo circular shifts, logical boolean functions, and modular additions.

Step 4: Avalanche Effect Analysis

Modify a single character or bit in the input message. Compare the resulting 160-bit digest with the original output to calculate the bit-flip diffusion percentage.
