# Access Control Fundamentals

Study and implement an access control mechanism to determine whether a subject is permitted to perform a requested operation on an object.

## Input
- Subject identity, role/clearance, object resource identifier, requested operation (Read, Write, Execute, Delete)

## Output
- Access decision (Grant / Deny) with audit policy log

## Test
- Test valid subject permissions resulting in Access Granted, and unauthorized subject requests resulting in Access Denied.
