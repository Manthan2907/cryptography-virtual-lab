Access Control Fundamentals

Study and implement an access control mechanism to determine whether a subject is permitted to perform a requested operation on an object.

Aim & Objectives

Aim: Study and implement an access control mechanism to determine whether a subject is permitted to perform a requested operation on an object.

Objectives:

  • Distinguish between subjects, objects, operations, and permissions.
  • Examine Discretionary Access Control (DAC), Mandatory Access Control (MAC), and Role-Based Access Control (RBAC).
  • Simulate policy enforcement decisions and authorization checks.

Theory

Access control is the selective restriction of access to a place or other resource. In computer security, access control involves three primary abstractions: Subjects (active entities like users or processes), Objects (passive resources like files, records, or devices), and Operations (read, write, execute, delete). Security models include DAC (owner decides), MAC (security labels/clearance), and RBAC (roles determine rights).

Procedure

  2. Select the target Object (e.g., Financial_Report.pdf, System_Kernel.bin).
  3. Select the requested Operation (Read, Write, Delete).
