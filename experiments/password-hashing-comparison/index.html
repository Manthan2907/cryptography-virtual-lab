Password Hashing Comparison

Compare MD5, SHA-1, SHA-256, bcrypt, scrypt, and Argon2 for password hashing and analyze their security characteristics.

Aim & Objectives

Aim: Compare MD5, SHA-1, SHA-256, bcrypt, scrypt, and Argon2 for password hashing and analyze their security characteristics.

Objectives:

  • Contrast fast general-purpose hashes against slow, adaptive password key derivation functions.
  • Evaluate the vulnerability of unsalted and fast hashes to GPU dictionary attacks and rainbow tables.
  • Understand the role of computational cost factors, memory hardness, and salt in password defense.

Theory

General-purpose hash functions (MD5, SHA-1, SHA-256) are engineered to be extremely fast for verifying file integrity. However, when used for password storage, their speed enables attackers to compute billions of guesses per second on consumer GPUs. Modern password storage requires slow, adaptive algorithms: bcrypt (computational hardness), scrypt (memory hardness), and Argon2 (PHC winner resisting both GPU and cache side-channel attacks).
